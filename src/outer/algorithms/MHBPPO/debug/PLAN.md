# MHBPPO 后期重复匹配调试计划

保持四个离散头完整的 CU 动作空间，由网络学习避免重复匹配。训练使用 8 个环境的全部样本，按整批 320 个时隙报告原始平均 reward 和完成率。

## 1. 在 actor loss 中加入期望重复匹配惩罚

**状态：代码已实现；2026-11-06 首次完整训练核验显示改善，末 500 轮满分比例 58.0%，尚未达到超过 80% 的目标。**

- 对每个状态和 CU，利用独立离散头的概率计算现有频谱惩罚 `max(选择次数 - 1, 0)` 的期望。对 CU 求和、对 minibatch 取平均，以可配置权重加入 actor loss。所有 CU 继续参与采样和 PPO 概率计算。
- 首次消融只开启期望惩罚，固定原有环境奖励、离散和连续熵系数、学习率、场景、种子及训练轮数。
- Python 参数 `--expected_duplicate_matching_coef` 默认 `0`，供基线使用。首次实验系数取 `0.1`；2026-11-06 起，MHBPPO 后台脚本默认传入 `0.3`，供第二次独立调权重实验使用。命令行可显式覆盖该值。
- `mhbppo_train.log` 和 `training_updates.csv` 记录 `actor_expected_duplicate_matching`。该值是更新后 actor 在本批次状态上的期望惩罚均值。实际重复匹配率使用同一轮采样数据的 `spectrum_penalty_rate`（文本日志里的 `spectrum`）。关闭辅助损失时，期望值记为缺失。
- 本地 CPU 验证已通过。对照枚举的 81 种分配，核对了期望公式、四个离散头的梯度及原有 log-prob 和熵。合成批次上的一次 PPO 更新降低了期望惩罚。完整环境的训练效果等待新运行日志。
- 历史基线为运行 `2026-11-04_10-33-41` 的第 2501–3000 次更新。整批 `320/320` 全成功的更新有 `173/500`（34.6%），重复匹配涉及 `544/160000` 个时隙，内层无解涉及 `23/160000` 个时隙。验收目标为新运行最后 500 次更新至少 `401/500` 次整批全成功，同时比较实际重复匹配率、内层无解率、原始 reward 和能耗。
- 用户已提供本次运行的 `mhbppo_train.log` 和 `training_updates.csv`，核验结果及后续优先级见第 6 节。下一次优先单独测试 `expected_duplicate_matching_coef=0.3`，其余设置沿用本次 8env 运行；该候选系数的效果待验证。

从仓库根目录启动当前的系数 0.3 实验。若历史基线使用了自定义配置，附上同一份 `--config`，并用命令行显式指定本次系数。

```bash
bash src/outer/algorithms/MHBPPO/run_background.sh start --max_updates 3000 --expected_duplicate_matching_coef 0.3
```

## 10. Pure 连续动作范围与条件时间解码

**状态：2026-11-06 已完成推导与配对诊断，其后已实现保留时间头的条件解码，验证见第 11 节。**

- 完整推导及实施边界见 [时间动作可行域分析](../../Pure_MHBPPO/debug/ACTION_SPACE_ANALYSIS_2026-11-06.md)。第 9 节「连续熵退火优先」适用于只调整学习参数的路线；若允许利用已知物理结构，应优先研究时间动作条件可行化，并与单独退火做对照。
- 当前 Pure 只保证独立 box 范围；未保证 `c_j >= d_s+u_i`、上传量对应时间下界，以及总 CPU 耦合。由每任务频率不超过全 BS，得必要上界 `c_j <= D_j-C_j*L_j/F_max`。这类规则不同于按历史样本随意裁窄速度或波束范围。
- 固定非重复匹配、CU 功率、波束与状态后，速率与工作量已固定；UAV 最短上传时间 `u_i*=Q_i/R_ui`，CU 时间由上传与新鲜度下界的最大值给出。当前 `R1,R2 <= R3`，故 CU 时间下界随 UAV 时间非减，总计算频率和能耗随时间非减。若该分量最小向量仍超过总 CPU 或时延预算，则此前缀无法仅靠调整时间补全；不是整个 P0 无解。
- 在其他约束可行、速率/任务正且无跨槽时间状态的当前硬约束模型中，该最短时间向量也是条件能耗最优解。可以研究保留时间动作的条件解码，或将 14 个时间维从 116 维 actor 中解析消去。后者属于结构变体；不声称等价于所有允许失败换低能耗的罚函数 MDP 动作。
- 对 iter_1000/3000/5000/28000 分别采样 8×40 槽，保持其他动作完全相同，只替换不重复匹配样本的时间，重复匹配原样保留。完成率分别从 16.5625/32.5/50.625/95.9375% 变为 63.75/88.125/95/100%；reward 分别从 -0.197855/0.138095/0.399623/0.904897 变为 0.274520/0.694814/0.843843/0.945991。

- 实施时须保持 PPO 潜变量、执行解码与 old/new log-prob 契约一致。共享算力不能简单用独立区间或固定平均配额替代；空区间不能强行夹成 epsilon 后当作可行。相关细节及数值余量边界见分析文档。
