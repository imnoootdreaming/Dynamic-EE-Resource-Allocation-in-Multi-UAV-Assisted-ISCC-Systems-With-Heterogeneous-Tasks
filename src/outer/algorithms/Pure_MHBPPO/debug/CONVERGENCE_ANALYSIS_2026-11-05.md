# Pure-MHBPPO：5000 轮以内收敛的诊断

结论：当前证据最支持先测试连续动作熵退火，再处理连续约束的反馈和动作初始化。不能把 MHBPPO 的「优先消除重复匹配」直接移植为 Pure 的第一优先级；不能保证仅调整某个参数就能在 5000 轮内达到原运行的最终性能。本轮只分析 Pure，未修改其学习公式或超参数。

## 3. 优先诊断：策略分布过宽，而非只缺少更大的更新步长

### 3.1 分布的中心可能较早可用，随机样本仍大量越过可行边界

| 保存模型 | 随机 320 槽 reward / 完成率 | 均值+argmax 40 槽 reward / 完成率 |
| --- | --- | --- |
| iter_1000 | -0.197855 / 16.5625% | 0.806571 / 90.0% |
| iter_3000 | 0.138095 / 32.5% | 0.908247 / 97.5% |
| iter_5000 | 0.399623 / 50.625% | 0.941517 / 100.0% |
| iter_7000 | 0.824280 / 89.0625% | 0.905613 / 95.0% |
| iter_10000 | 0.901991 / 95.9375% | 0.784163 / 82.5% |
| iter_28000 | 0.904897 / 95.9375% | 0.962045 / 100.0% |

这些是新采样复评，不能冒充原训练记录。每个确定性结果仅来自一个固定场景回合，且改变动作会改变后续状态；不能据此声称第 3000 或 5000 轮已按原训练口径收敛。iter_10000 的均值策略反而有 7/40 槽感知 SINR 失败，也说明均值/argmax 不保证始终更好，不能用更换评价口径来宣称训练加速。

Pure 有 116 个连续维度和 4 个十分类离散头。Beta 初始化近似 alpha=beta=softplus(0)+1，其归一化动作标准差约 0.2387。复评 iter_1000 时，多数连续头标准差已增至 0.283–0.287，接近均匀分布的 `1/sqrt(12)=0.2887`；iter_5000 的 UAV 卸载时间头仍为 0.2803，CU 卸载时间头为 0.2191。分布很宽与固定熵正则鼓励探索的机制相符，但降低熵权重是否足以加速仍需消融。

代码固定 `continuous_entropy_coef=0.05`、`discrete_entropy_coef=0.01`，并在入口拒绝覆盖。其连续熵按 116 维求和，离散熵按 4 头求和。连续微分熵可以为负，不能把两种熵的符号或大小直接等同于策略质量。

末 5000 轮连续熵对 actor loss 的平均贡献约 `+0.264499`，离散熵贡献约 `-0.001778`，合并后的 PPO surrogate loss 约 `-0.052123`，最终 Actor_Loss 约 `+0.210598`。正的 Actor_Loss 不是发散证据；这些标量大小也不能替代实际梯度范数比较。

### 3.2 第 5000 轮主要瓶颈是连续服务可行性

iter_5000 的 320 槽随机复评中，服务约束罚均值 `0.459375`（147 槽），频谱重复匹配罚均值 `0.05`（16 槽），碰撞罚为 0。具体约束失败次数为：任务新鲜度 112、CU 上传量 98、BS 总算力 48、重复匹配 16。各类失败会重叠，不能相加当作失败时隙总数。

原日志最后 12 个完整物理回合组中：服务罚 187/3840，重复匹配罚 5/3840，碰撞为 0；任务新鲜度失败 93、CU 上传量失败 86、BS 总算力失败 76。原始 reward 均值满足 `0.948214（能量项）-0.048698（服务罚）-0.001302（频谱罚）=0.898214`。这只描述末 12 轮，不代表全部末期或早期分布。

因此，Pure 的优先级应为连续时间/资源动作的可行性与探索控制，再考虑匹配辅助损失。原奖励将服务约束失败合并成 0/1：轻微越界与严重越界得到相同的这一项罚值，缺少约束严重程度的引导；能量项仍可能不同，不能说所有不可行动作的总奖励完全相同。

### 3.3 学习率和 KL 不支持直接盲增 actor_lr 或 epochs

历史配置为 actor/critic_lr=3e-4，episodes=8000，max_updates=0，lr_min_ratio=0.1。根据实际调用顺序，第 5000 轮使用的学习率约 `1.13e-4`；从约第 7202 轮开始使用下限 `3e-5`，并没有在第 8000 轮归零。因此平台不是学习率变零造成的冻结。

第 4001–5000 轮记录的 KL 估计均值 0.069785、95 分位数 0.129353。它是同批采样动作上的 `mean(logp_old-logp_new)`，可能为负，不是逐状态分布的精确 KL。缺少连续/离散 clip fraction、分头精确 KL、比率分位数与解释方差，不能据此认定「更新一定过大」或「一定太保守」；至少没有充分依据优先把 actor_lr 翻倍或 epochs 从 5 提到 10。[1]

特别注意：`configure_ppo_lr_horizon()` 会用正的 max_updates 覆盖 episodes。直接加 `--max_updates 5000` 会把衰减区间从 8000 改成 5000，约第 4502 轮就开始使用下限；同时传 `--episodes 8000` 也不能保留原区间。仅缩短训练预算不是学习加速，甚至可能更早限制学习。

### 3.4 动作初始化和高维探索存在明显的物理先验改进空间

第 4001–5000 轮约 90.57% 的加权能耗来自飞行，末 5000 轮约 98.99%。按当前飞行模型 `E_flight=c1*d^3/T^2+c2*T^2/d`，仅最小化单槽飞行能耗得到 `v*=(c2/(3*c1))^(1/4)=5.42681 m/s`，而近对称 Beta 初始均速约 `(5+40)/2=22.5 m/s`。可优先研究有适当方差的距离头初始化先验，而不是让其从高速宽分布开始搜索。

该速度仅是飞行子问题的最优解；运动还影响感知、信道和后续状态，不能把它硬固定成整个 ISCC 问题的最优控制。若做先验初始化，应保留可调整空间，并将其作为独立实验。

80/116 个连续维度是卸载波束实虚方向，复评中标准差长期接近 0.287。解析波束可以减少维度，但 MRT 会同时改变 UAV 链路和 CU 干扰，限制策略空间，属于新的结构消融。不能声称移除这 80 维对原问题无损，也不应与原 Pure 基线混称。

## 4. 面向 5000 轮预算的实验优先级

所有数值均是待验证候选，未运行从头训练。先固定 8env、40 槽、网络、场景、原始奖励和初始化，做单因素对照，再组合有效因素；不要一次同时改变熵、学习率、epochs 和辅助奖励。

| 优先级 | 候选改动 | 首轮候选与验证目的 | 现有入口能否直接使用 |
| --- | --- | --- | --- |
| 0 | 明确停止预算与 LR 区间 | 将训练停止轮数与学习率衰减区间解耦；第一组保留原 8000 衰减区间，仅在 5000 轮验收 | 不能用现有 max_updates/episodes 组合实现解耦，需小改参数 |
| 1A | 仅连续熵退火 | 0–1000 轮保持 0.05，第 1000–3500 轮线性降至 0.005，之后保持；先检查持续可行性是否提早上升 | 需开放 Pure 参数并增加调度，当前被固定值检查拒绝 |
| 1B | 仅离散熵退火 | 保持连续熵 0.05，离散熵 0.01 在 1000–3500 轮降至 0.001；检验匹配探索的独立作用 | 同上；不能冒充 MHBPPO 后期最后 20% 的原计划 |
| 2 | 连续约束的稠密训练反馈 | 对 freshness、CU bits、BS frequency 使用有界、无量纲残差罚；先试小权重如 0.05 或 0.1，原始 reward 单独照常报告 | 需新增实现；这是目标塑形，不能保证原最优策略不变 |
| 3 | 距离/时间头的初始化先验 | 单独测试距离均值向飞行子问题经济速度靠近，或可行性敏感时间头更小的初始标准差；保留探索 | 需新增实现，不宜直接套统一紧分布到全部动作维度 |
| 4 | 期望重复匹配辅助项 | 必要时再从系数 0.05–0.1 单独测试；5000 轮诊断中服务罚约为其 9 倍，因此不是首选 | 当前 Pure 接口虽解析相关公共参数，agent 并未使用，不能仅传参就宣称开启 |

若新增残差罚，应通过训练 reward/return 进入 PPO；把 NumPy 算出的残差常数直接加到 actor loss 不会自动给 actor 提供所需梯度。对动作相关的残差罚，不得声称其天然具有策略不变性。若要求理论上的策略不变性，可研究满足条件的势函数塑形 `gamma*Phi(s_next)-Phi(s)`，有限回合还需处理终端势值；该保证不能套到任意约束残差罚上。[3]

学习率和 minibatch、epoch 数当然值得研究，但本次证据不足以给出唯一最优值。实现细节对学习速度的作用具有任务依赖性，其他基准中的经验不能证明本系统能在 5000 轮内收敛。[2]

## 5. 验收口径与耗时问题

- 建议先用原场景 seed=42 筛选，再至少用 3 个配对种子复核。每个种子内，基线与候选保持同场景与初始化规则。当前 seed 同时影响外生场景和动作随机种子；若要固定场景仅改变策略随机性，应先解耦并记录场景签名。
- 主要验收仍用随机策略、全 320 槽的原始 reward 和完成率。确定性评价另列；训练辅助 reward 不得替换原始 reward。报告到达阈值的更新次数、环境步数和真实墙钟时间。
- 从 8env 改为 16env 时，5000 轮样本数从 160 万变成 320 万；固定 minibatch=32、epochs=5，每轮梯度步从 50 变成 100。即使轮次减半，也不能直接称为样本效率或耗时提升。当前多个环境共享固定外生场景，更多 worker 主要增加动作采样，不能当作更多独立场景。
- 日志显示原前 5000 轮耗时约 4.14 小时。Pure 每槽物理日志都执行 JSON 序列化与 flush，另有动作/环境日志。降低详细日志频率、按轮 flush、数组批量转 tensor、减少进程间大 trace 传输可能减少单轮耗时，但这些不会直接减少达到同一性能所需的更新次数。
- 当前只有整轮 elapsed_seconds，没有采样/传输、写日志、PPO 更新的分别计时，不能把 CPU、磁盘或训练器中的某一项确认为主要耗时瓶颈。建议先增加三段计时再优化吞吐。
- 暂不优先：盲目增大 actor_lr、加倍 epochs、加宽网络、直接把训练上限设成 5000、减轻任务负载。前四项缺少消融支持，最后一项会改变问题难度。

## 6. 统计与因果边界检查

11/11 类检查已覆盖。无 p 值或独立样本显著性检验；不把高度相关的训练轮次或重叠滑动窗口当作独立重复实验。

| 检查 | 本次处理 |
| --- | --- |
| Simpson 悖论 | 同时列训练阶段、随机/确定性评价及约束分项；尚无跨种子分层证据 |
| 生态谬误 | 整批完成率不等同于每个 CU、每种任务、每个场景均可靠 |
| Berkson/选择偏差 | 明确固定场景、已保留日志范围、有限快照与采样种子 |
| 碰撞变量偏差 | 无控制变量回归；不按可行样本筛选主要 reward 结论 |
| 基准率忽略 | 失败数给出全部时隙分母；约束重叠不简单相加 |
| 均值回归 | 不用最佳单轮或单个确定性满分回合证明持续收敛 |
| 幸存者偏差 | 原 CSV 包含全部完整轮次；说明中断半轮与滚动裁剪缺失 |
| 多重搜寻 | 所有六个快照结果均列出，包括较差的 iter_10000 确定性结果 |
| 分析路径自由度 | 阈值、窗口和候选参数均标为事后诊断或待预设验收规则 |
| 相关不等于因果 | 熵、critic loss、reward 随时间共变；不据此宣布熵退火已有效 |
| 反向因果 | 更好的回报也可能让策略更集中；需单因素训练对照区分 |

复现结论：现有日志统计已核验，快照为新诊断采样；未重跑 28117 轮原训练，也未完成任何加速训练消融。缺失的关键证据是早期逐约束 trace、clip fraction/分头 KL、分阶段耗时及多种子训练结果，它们分别用于定位早期可行性瓶颈、更新幅度、耗时瓶颈和加速方案的可靠性。
