# MHBPPO 完成率诊断（2026-10-09）

## 结论

本次低完成率主要是当前策略给出的 CU 匹配/功率与此前 UAV 轨迹共同造成的感知 SINR 不可行，不能归结为“训练步数不足”，也不能把日志中的 infeasible 解读成整个时隙对所有动作都不可行。

在第 2001–2500 轮的 20,000 个时隙上，保持原有 UAV 位置、运动轨迹、卸载时长和实际目标匹配接收波束，仅重选一对一 CU 匹配并将 CU 功率降至现有合法下限 0.01995262315 W，能直接构造 13,759 个满足原始约束的秩一可行解（68.795%）。其中 10,298 个是原策略失败的时隙，占原失败时隙的 62.26%。68.795% 是对这组已记录状态和固定匹配波束的离线结果，不是重新训练后的完成率预测，也不是整个系统的全局上限。

其余 6,241 个时隙（31.205%）在这些位置和固定匹配波束下，即使所有 CU 使用合法最小功率，也不存在满足感知约束的一对一 CU 匹配。这部分不能仅靠当前时隙的 CU 匹配、功率或卸载时长修复；此前轨迹或接收波束规则仍然可以改变其可行性。

## 感知不可行证据

令 G_i=A_i^H g_i g_i^H A_i，Gamma_i=Σ_j eta_ij p_j |g_i^T h_ij|²+sigma²。这里的转置按当前 inner/environment.py 第 277 行的实际计算实现，并非对论文复数信道记号的重新解释。

感知约束要求 Tr(G_i W_i) >= epsilon Gamma_i，且 W_i 半正定、Tr(W_i)<=P_max。由特征值上界，任意可行 W_i 必须满足：

    m_i = P_max lambda_max(G_i)/(epsilon Gamma_i) >= 1。

m_i<1 直接证明固定外层动作的内层问题不可行，不依赖 MOSEK 是否收敛。在本项目 rank-one 感知信道与匹配接收波束下：

    lambda_max(G_i)=xi_0 rho_ref N²/d_i⁴。

后期 20,000 个时隙中：

- 16,530 个（82.650%）至少一架 UAV 的 m_i<1。
- 14,019 个日志 infeasible 时隙全部违反该上界。
- 2,515 个 unknown 时隙中有 2,511 个也违反该上界。因而这次 unknown 样本大多也有固定动作不可行的解析证据，不能一概当成单纯的数值问题。
- 原动作下没有检测到乐观 CU 传输/BS 计算必要下界的冲突；这只是下界检查，不能单独证明原动作满足这些约束。

通过合法最小 CU 功率计算每个 UAV–CU 候选对的 m_ij，把 m_ij>=1 的对作为二分图边，检查是否存在覆盖所有 UAV 的一对一匹配。通过比例是 68.795%。随后构造完整原始约束可行解，证实这里通过的所有候选确实可行。

## 完整可行解如何构造

每个可行状态选一对一 CU 匹配、全部 CU 功率置合法下限，保持原接收波束和卸载时长：

1. 令感知发射波束沿目标导向矢量，功率取 epsilon Gamma_i/lambda_max(G_i) 加 1e-6 相对裕量。
2. 依据实际感知 SINR 计算感知辅助变量 z_i，并加相对裕量。
3. 令 UAV 卸载发射波束沿 BS 信道，功率取满足 z_i<=D_i_off B log2(1+Tr(H_i B_i)/Phi_i) 的解析下界，再加裕量。
4. 计算 CU 在感知共享阶段、UAV 卸载共享阶段和剩余独占阶段的真实传输速率，选择满足 170 kbit 数据传输与新鲜度条件的 CU 卸载时长。
5. 根据实际剩余计算时间设置 UAV/CU 最小 BS CPU 频率，检查总 CPU 频率不超过 10 GHz，同时检查功率与时延。

生成的发射矩阵是波束向量外积，天然半正定且秩一，不依赖 PC3P 的收敛状态或秩恢复。结果见 constructive_summary.json；保存了 40 个具体解证据 constructive_witnesses.json。桥接层派生常数的独立复核结果见 witness_verification.json。

## 额外发现：求解状态需要原始残差复核

对 32 个原失败状态仅改变 CU 匹配/功率后重新运行本地 PC3P：32 个均返回有限目标值及 PrimalAndDualFeasible，但独立复算时有 27 个返回解不满足 c08 UAV 卸载数据约束（依据返回的实际矩阵、z 与信道）。此发现需要进一步定位数值尺度或返回解处理问题，当前不把它确定归因于某一行代码，也不把 32 个 solver 状态都作为真实可行证据。上述 68.795% 结论使用解析构造的秩一解，避免依赖这一问题。

目前 completion 的 success 条件只检查无解/碰撞/频谱惩罚，并不逐条检查原始约束或 rank-one 残差。因此有限目标值率和 solver_status 不足以单独证明实际所有任务完成。

## 训练与动作设计的优先改进

1. 首先记录感知裕量和原始约束残差，建立上述可行性分类。
2. 实现以感知裕量为依据的一对一 CU 匹配基线/动作屏蔽，联合处理 CU 功率；只有解决重复匹配并不等于选择了对感知有利的 CU。
3. structured_beam_alpha=0 时禁用无物理作用的 80 个波束动作维度，或至少将它们从连续动作 ratio 与 entropy 中移除，采样 old log probability 与 learner evaluate 必须同步修改。当前 102 个连续维度中 80 个不影响环境，但仍参与同一 continuous PPO ratio 和熵正则。这是效率/梯度方差问题，不意味着 PPO 数学上必然无效。
4. 对失败动作提供可分辨的感知裕量反馈：当前统一 -1 无法区分轻微越界与差几个数量级。若改变 reward shaping，需要明确其权重及对优化目标的影响。
5. 以当前/下一窗口目标的轨迹启发式或演示初始化，提升跨窗口接近目标的能力；保持相同物理参数对比，而不是仅增加训练步数。
6. 增加连续/离散分头 entropy、approx_KL、clip_fraction、感知裕量、按窗口完成率及评估曲线。固定布局可先排障，再用多种独立布局检验泛化。

## 修改信道/衰减参数的判断

可以扩大可行域，但应在动作改进之外作为独立消融实验，并同步修改内外层模型。改变物理参数后再提高 completion 不能证明原策略已经解决原问题。

- 增大 RCS xi_0 或独立感知增益，感知功率上界中的分子线性增大；提高 UAV 功率上限或降低感知 SINR 门限也能放宽这条约束。但 RCS/功率会连带影响感知数据量、能耗及其他约束，完整完成率仍需重算。
- 用固定原动作仅检查 c06：感知分子增益 1×/2×/3.162×/10×/100× 时，通过率分别为 17.350%/20.165%/22.330%/32.280%/62.215%。例如 xi_0=0.1 改为 1 对应 10×。这些是必要约束通过率，不是完整求解成功率，也没有重新训练。
- 不宜盲目把所有链路的参考增益一起调大。若共同增益倍数为 k，m_i(k)=k P_max lambda_i/[epsilon(k I_i+sigma²)]；在干扰占主导时趋于 P_max lambda_i/(epsilon I_i)，提升会饱和。
- 降低 alpha_uav_link 会增强 CU→UAV 的干扰，也增强 UAV→BS 通信；不保证感知更可行。当前外层把 alpha_1 与 alpha_2 都映射到 alpha_uav_link，单独修改 inner Parameters.alpha_2 不能改变外层这条链路，须先分离接口。
- 改善 CU→BS 链路（例如在有物理依据下调整 alpha_3）能够降低完成 CU 传输所需的 CU 功率；本次无需改链路，现有最低功率已经足以完成上述 68.795% 的构造解。
- 目标距离对感知信号是 d^-4；缩短距离通常比统一增强信道更有针对性。同干扰水平下距离减半，感知分子约提高 16×。缩小部署区域或改善轨迹都会影响距离，但前者改变了场景难度。
- Parameters.__post_init__ 派生了 rho_ref/sigma²/eps_sinr/Pmax 等字段；直接赋值原始 dB 字段不会自动更新这些派生值。参数消融需重建 Parameters 或显式同步派生字段。

优先建议：在现有参数下先修复 CU 匹配/功率与轨迹，再以相同种子进行 RCS、门限、不同链路衰减系数的独立消融。
